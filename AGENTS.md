# Правила работы с прототипом

Конечный пользователь — геймдизайнер без опыта программирования и терминала. Цель — быстро проверять игровые гипотезы, а не строить универсальный движок. Общайся по-русски, простым языком; не требуй от пользователя править код, выполнять команды или настраивать серверы и зависимости.

## Запуск и устройство

- Запуск на Windows — двойным щелчком по `Play.cmd`: он использует установленный Python 3 и запускает локальный сервер; после игры пользователь закрывает его окно. Порт выбирается автоматически. Серверу не нужны сторонние библиотеки и интернет. Phaser 3 и ресурсы находятся в проекте. Не требуй Node.js, сборщиков или сетевых CDN для запуска игры.
- Прямой запуск через `file://` оказался ненадёжным при загрузке текстур. Проверяй ресурсы и механику в реальном браузере через локальный сервер. Python-окружение для инструментов разработки создавай в `.venv` проекта; оно не является требованием для запуска игры.
- Сохраняй понятное сообщение об ошибке запуска. Избегай лишних библиотек, сложной архитектуры и панелей, которые не нужны текущей гипотезе.

## Изменения и проверка

- Реализуй запрошенную механику, сохраняя работающий запуск; добавляй сброс, настройки или тестовые сценарии, когда они полезны. Не подменяй поведение игры декоративной демонстрацией.
- По возможности открывай `index.html` непосредственно в браузере, проверяй ошибки JavaScript и действия пользователя, в том числе сброс и реальные правила механики. Успешное открытие страницы не доказывает корректность механики. Если автоматизация браузера недоступна, выполни доступные проверки и прямо сообщи об ограничении; не утверждай, что проверил то, чего не проверял.
- Инструменты проверки используй только если они доступны агенту; не превращай Node.js, Playwright или иные инструменты разработки в обязательные условия запуска игры пользователем.
- Учитывай уже сделанные изменения пользователя. Не выполняй разрушительные Git-операции без разрешения. Сохраняй версии по просьбе пользователя; при возврате к предыдущей версии сначала выясни, как поступить с несохранёнными изменениями.
- В ответе кратко объясняй, что изменилось, как открыть или обновить игру и что было проверено. Указывай существенные ограничения понятными словами.
