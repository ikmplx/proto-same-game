# 2D-шаблон

## Как запустить

На компьютере должен быть установлен Python 3. Откройте папку проекта и дважды нажмите на **Play.cmd**. Игра откроется в браузере; интернет и дополнительные библиотеки не нужны. Во время игры оставьте открывшееся окно сервера открытым. Закончив играть, закройте это окно — сервер остановится. Если браузер не открылся автоматически, адрес игры указан в окне сервера.

Нажмите на группу из трёх или более клеток одного цвета, соединённых сторонами, чтобы её убрать. Клетки сверху опустятся вниз. Новые клетки не появляются. Кнопка «Начать заново» создаёт новое поле и сбрасывает счётчик. Чтобы увидеть изменения, внесённые Codex, обновите страницу браузера.

## Как начать новый эксперимент

Скопируйте папку проекта без папки `.venv`, дайте копии новое имя и откройте её как проект в Codex. Опишите, что хотите проверить. После изменений обновите страницу браузера или снова запустите Play.cmd.

Если игра не запускается, попросите Codex проверить проект и передайте ему текст сообщения об ошибке. Для работы игры нужны `Play.cmd`, `server.py`, `lib/phaser.min.js` и `assets/token-128.png`. Исходная текстура сохранена в `assets/token.png`.

Рабочие версии можно сохранять с помощью Git. Попросите Codex сохранить текущую версию, когда будете довольны результатом; перед возвращением к старой версии уточните, что должно произойти с текущими изменениями.
